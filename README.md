# escape-to-albania
Demo website for Escape to Albania: 4 design models (1a Udha, 1b Dielli mbi det, 1c Plot & Kontur, 1d Dera), each with Home, Tours, About and Contact pages.

Open index.html to choose a model.

## Production site (design 1c)

`site-1c/` is the chosen design (1c · Plot & Kontur) prepared for Cloudflare Pages, with the journal (blog), booking API and the admin CMS at `/admin/`. See [site-1c/README.md](site-1c/README.md) for deploy steps (Root directory `site-1c`, output `public`).
